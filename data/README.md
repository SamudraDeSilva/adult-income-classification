# Dataset details — Adult Income Classification

**File:** `adult_income_classification_dataset.csv`  
**Dimensions:** 45,222 rows × 14 columns  
**Target:** `income` (`<=50K`: 34,014; `>50K`: 11,208)

The dataset is a cleaned derivative of the historical **Adult (Census Income)** benchmark. The exact Kaggle download listing for this cleaned file has not been independently verified. The notebook uses the included CSV for all models and figures, normalises categorical whitespace and applies training-only feature preprocessing. The records should not be treated as a representation of current income conditions.
